= Workshop Instructor

This page is for the instructor who runs a delivery of the workshop.

== What the Workshop Covers

Attendees should know the basics of Kubernetes (pods, services, deployments and namespaces), be able to read YAML, and have used the `oc` command line.
Each workshop's start page lists its own prerequisites and what attendees can do afterwards.

== Environment and Requirements

Each workshop lists the cluster components, Operators, command-line tools, roles and access it needs on its own page.
Prepare everything for the workshops you deliver:

* xref:helm:setup-requirements.adoc[Helm Workshop]
* xref:deploy:setup-requirements.adoc[Advanced Deployment Workshop], including the read-only attendee RBAC in `workshops/deploy/provisioning/attendee-rbac.yaml` in the workshop repository
* xref:istio:setup-requirements.adoc[Istio Service Mesh Workshop], including the Service Mesh versions and control plane revision the pages show
* xref:prometheus:setup-requirements.adoc[Prometheus Query Workshop]
// add-workshop.py adds workshops above this line

Shared by all the workshops: attendees who don't want to install the command-line tools run the workshop CLI tools image on the cluster, as xref:cli-tools.adoc[Shared CLI tools] describes.
Make sure attendees can pull that image, or mirror it for a disconnected cluster.

xref:downloads.adoc[Downloads] has every file of the release: the PDF, the Helm chart, the list of images to mirror and the guide for running the workshop in a disconnected cluster.

== Before the Day

. Prepare the environment from the setup requirements above, for every attendee.
. Run the workshop end to end once on an environment built the same way.
. Send attendees the xref:attendee.adoc[Workshop attendee] page so they can check their workstation.
