= Exercises
:hardbreaks-option:

== Exercise 1: Basic Aggregations

Practice using basic aggregation functions to summarize metrics. As in the module content, the queries use `container!=""` and `container!="POD"` so that each series is exactly one container, and `rate()` to turn the CPU counter into current CPU usage.

=== Step 1: Sum Aggregation

Write a query to calculate the total memory usage across all containers in your cluster:

[source,promql]
----
sum(container_memory_working_set_bytes{
  container!="",
  container!="POD"
})
----

Execute this query in Prometheus and observe the result.

=== Step 2: Sum by Namespace

Modify the query to show total memory usage per namespace:

[source,promql]
----
sum(container_memory_working_set_bytes{
  container!="",
  container!="POD"
}) by (namespace)
----

Compare the results with the previous query. How many namespaces do you have?

=== Step 3: Average Memory Usage

Write a query to calculate the average memory usage per namespace:

[source,promql]
----
avg(container_memory_working_set_bytes{
  container!="",
  container!="POD"
}) by (namespace)
----

Compare the average with the sum. What insights can you draw?

== Exercise 5: Combining Aggregations

Practice combining multiple aggregation functions and filters.

=== Step 1: Average of Maximums

For each namespace, calculate the average memory usage of the largest container in each pod. The inner `max` picks the container with the highest memory usage in each pod, and the outer `avg` averages those values over the pods of the namespace:

[source,promql]
----
avg(max(container_memory_working_set_bytes{
  container!="",
  container!="POD"
}) by (namespace, pod)) by (namespace)
----

This shows how much memory the largest container of a typical pod in each namespace uses. It is a snapshot at the evaluation time, not a peak over time: `max` compares containers with each other, not samples over time. Module 4 introduces `max_over_time()`, which finds the peak of each series over a time range.

=== Step 2: Filtered Aggregation

Calculate the total memory usage only for namespaces that match a specific pattern (e.g., starting with "openshift-"):

[source,promql]
----
sum(container_memory_working_set_bytes{
  namespace=~"^openshift-.*",
  container!="",
  container!="POD"
}) by (namespace)
----

Adjust the pattern to match namespaces in your cluster.

=== Step 3: Multi-Label Grouping

Group memory usage by both namespace and node:

[source,promql]
----
sum(container_memory_working_set_bytes{
  container!="",
  container!="POD"
}) by (namespace, node)
----

This shows how memory is distributed across nodes within each namespace.

If you can answer yes to all these questions, you are ready to proceed to the next module on advanced query patterns.
